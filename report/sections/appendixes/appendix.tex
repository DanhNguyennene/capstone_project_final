\chapter{Evaluation Artifact Appendix}
\label{appendix:test-cases}

This appendix summarizes the evaluation artifacts used by the scenario-grid benchmark. The active curated dataset is \texttt{slurm-agent/evaluation/dataset.json} and contains 3,135 manually constructed synthetic cases across eleven balanced categories. A separate 40-case paraphrase/generalization split is stored as a distinct artifact and must not be merged into the curated benchmark score.

\section{Artifact Locations}

The relevant machine-readable artifacts are stored in:

\begin{itemize}
    \item \texttt{slurm-agent/evaluation/dataset.json}
    \item \texttt{slurm-agent/evaluation/generalization\_dataset.json}
    \item \texttt{slurm-agent/evaluation/results/}
\end{itemize}

The active dataset artifact contains all 3,135 curated test definitions. The generalization artifact contains compact paraphrase cases that resolve against \texttt{dataset.json} at evaluation time. The results directory is the output location for benchmark run artifacts generated by the evaluator.

\section{Evaluation Output Checklist}

\begin{itemize}
    \item Export aggregate pass/fail and component-score tables for the active curated benchmark.
    \item Report the held-out paraphrase split separately from the curated benchmark.
    \item Include low-scoring case excerpts only from the same run artifact being reported.
    \item Add pass\textasciicircum{}k appendix tables from repeated runs with identical configuration.
\end{itemize}
