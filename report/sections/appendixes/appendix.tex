\chapter{Evaluation Artifact Appendix}
\label{appendix:test-cases}

This appendix summarizes the current evaluation artifact set for the scenario-grid benchmark. The active curated dataset contains 455 tests across 9 categories and 5 scenarios. A separate 40-case paraphrase/generalization split is stored as a distinct artifact and must not be merged into the curated benchmark score. Instead of embedding all per-test rows inline in this chapter, the report documents consolidated tables and points to machine-readable JSON/TeX outputs used for reproducibility.
