\section{Thesis Structure}
\label{sec:thesis-structure}

This thesis is organized into seven chapters, each addressing specific aspects of the research and development of the Slurm Agent system. The structure is designed to provide a logical progression from theoretical foundations through implementation details to experimental evaluation.

\textbf{Chapter 1: Introduction.} This chapter presents the motivation for developing an LLM-based agent for Slurm cluster management. It establishes the scope and goals of the project, identifies key challenges encountered during development, and outlines the solutions adopted to address them.

\textbf{Chapter 2: Theoretical Background.} This chapter provides the foundational knowledge necessary to understand the research. It covers Slurm workload management, including architecture and key concepts; Large Language Models and their capabilities; and the Model Context Protocol for tool integration. These concepts form the technical basis upon which the solution is built.

\textbf{Chapter 3: Related Tools and Works.} This chapter surveys existing solutions and related research in the domains of HPC management interfaces, LLM-based agent frameworks, and MCP implementations. It analyzes the strengths and limitations of current approaches, positioning the contribution of this research within the broader landscape.

\textbf{Chapter 4: Proposed Approaches.} This chapter presents the design of the Slurm Agent system. It begins with an introduction to the application concept, followed by detailed requirements analysis. The chapter describes the overall system architecture and the multi-agent design that enables specialized handling of different task types.

\textbf{Chapter 5: Implementation.} This chapter details the implementation of each system component. It covers the MCP server development for exposing Slurm functionality, the agent backend implementation using the OpenAI Agents SDK, and the frontend development including the SSE-based real-time update mechanism and visualization rendering.

\textbf{Chapter 6: Experiments.} This chapter describes the testing methodology and presents experimental results. It covers the testing approaches employed, the test environment configuration, and evaluation of the system's capabilities across various usage scenarios.

\textbf{Chapter 7: Conclusion.} This chapter summarizes the research contributions and findings. It discusses limitations of the current implementation and identifies opportunities for future work and potential extensions of the system.
