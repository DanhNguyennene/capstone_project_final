\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

High-Performance Computing (HPC) clusters have become essential infrastructure for scientific research, engineering simulations, and large-scale data processing. The Slurm Workload Manager is widely used across HPC environments and provides sophisticated resource management capabilities, but its command-line interface can create usability barriers for users who need to inspect queues, diagnose jobs, submit workloads, or perform controlled state-changing operations. This thesis addresses these challenges by designing and implementing an intelligent agent system that provides a natural language interface for Slurm cluster management.

The proposed Slurm Agent combines Large Language Models (LLMs), a FastAPI backend, an OpenAI-compatible streaming interface, and the Model Context Protocol (MCP) to bridge the gap between user intent and concrete Slurm operations. The current architecture separates the system into a React + Vite presentation layer, a session-aware agent orchestration layer, an MCP protocol/tool layer, and the underlying Slurm or mock-cluster infrastructure. Within the agent layer, a main reasoning agent coordinates read-only Observer behavior and state-changing Operator behavior, while auxiliary tools support chart artifacts, documentation lookup, confirmation handling, and evaluation tracing.

This thesis makes four main contributions. \textbf{(1)} It designs an end-to-end layered architecture for natural-language Slurm management, connecting a React + Vite interface, a session-aware FastAPI backend, OpenAI Agents SDK orchestration, MCP-based tool access, and real or mock Slurm infrastructure. \textbf{(2)} It implements a safety-centered Observer/Operator workflow that separates read-only analysis from state-changing execution through structured handoffs, human-in-the-loop confirmation, pending-action persistence, SlurmGuard admission checks, and session-scoped cleanup. \textbf{(3)} It develops a typed, guard-aware MCP Slurm tool layer that exposes command capabilities, validates parameters, formats command output for LLM consumption, and keeps natural-language reasoning decoupled from command execution. \textbf{(4)} It provides an architecture-aware evaluation stack and dashboard that run live agent requests against resettable mock scenarios, collect traces for tool usage, routing, confirmation behavior, response quality, and source-to-target state transitions, and optionally apply an LLM-as-judge component. The active scenario-grid dataset contains 1,800 curated cases across read, diagnosis, action, bulk, safety, submission, multi-step, accounting, and edge workflows, while the evaluation backend supports resumable and parallel runs with isolated agent sessions and worker-specific MCP state.

The implementation demonstrates the feasibility of a stateful, tool-grounded natural language interface for HPC operations while making clear that production deployment requires continued safety hardening, final frozen benchmark reporting, broader paraphrase evaluation, and validation on real clusters with site-specific policies. The system provides a practical foundation for future research on AI-assisted cluster operations, especially where usability, traceability, and controlled execution must be balanced.

\textbf{Keywords:} High-Performance Computing, Slurm, Large Language Models, Model Context Protocol, Multi-Agent Systems, Human-in-the-Loop, Natural Language Interface
