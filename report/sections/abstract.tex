\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

High-Performance Computing (HPC) clusters have become essential infrastructure for scientific research, engineering simulations, and large-scale data processing. The Slurm workload manager, deployed on the majority of the world's top supercomputers, provides sophisticated resource management capabilities but presents significant usability challenges due to its complex command-line interface. This thesis addresses these challenges by designing and implementing an intelligent agent system that provides a natural language interface for Slurm cluster management.

The proposed Slurm Agent leverages Large Language Models (LLMs) combined with the Model Context Protocol (MCP) to bridge the gap between user intent and system operations. The system implements a multi-agent architecture where specialized sub-agents handle different aspects of cluster interaction: an Analysis Sub-Agent for read-only queries, an Action Sub-Agent for job management, plus auxiliary tools for data visualization and documentation retrieval. Through MCP-based tool integration, the agent executes Slurm commands, interprets results, and presents information in accessible formats.

Key contributions of this research include: (1) a natural language interface enabling users to query cluster state without command syntax knowledge, (2) an MCP server implementation extending the protocol ecosystem to the HPC domain, (3) a multi-agent architecture with handoff mechanisms for specialized task handling, (4) integrated visualization capabilities for cluster metrics, and (5) a scenario-grid evaluation framework that scores architecture-level behavior (tool usage, routing, HITL, and state transitions).

Experimental evaluation on the current 455-case curated benchmark reports a pass rate of 93.6\% at a strict threshold ($\geq 0.80$), an average overall score of 0.936, Behavioral Agreement Rate (BAR) of 0.908, Cross-Scenario Robustness (CSR) of 0.934, and average response latency of 22.59 seconds. These results describe performance on the curated benchmark; robustness to arbitrary Slurm requests remains partially evaluated through a separate held-out paraphrase/generalization split.

The implementation provides a foundation for continued research in AI-assisted HPC operations, demonstrating the viability of LLM-based interfaces for complex system management while identifying concrete priorities for future enhancement, including safety hardening, submission workflow reliability, and production-cluster validation.

\textbf{Keywords:} High-Performance Computing, Slurm, Large Language Models, Model Context Protocol, Multi-Agent Systems, Natural Language Interface
