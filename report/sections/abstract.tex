\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

High-Performance Computing (HPC) clusters have become essential infrastructure for scientific research, engineering simulations, and large-scale data processing. The Slurm workload manager, deployed on the majority of the world's top supercomputers, provides sophisticated resource management capabilities but presents significant usability challenges due to its complex command-line interface. This thesis addresses these challenges by designing and implementing an intelligent agent system that provides a natural language interface for Slurm cluster management.

The proposed Slurm Agent leverages Large Language Models (LLMs) combined with the Model Context Protocol (MCP) to bridge the gap between user intent and system operations. The system implements a multi-agent architecture where specialized sub-agents handle different aspects of cluster interaction: an Analysis Sub-Agent for read-only queries, an Action Sub-Agent for job management, plus auxiliary tools for data visualization and documentation retrieval. Through MCP-based tool integration, the agent executes Slurm commands, interprets results, and presents information in accessible formats.

Key contributions of this research include: (1) a natural language interface enabling users to query cluster state without command syntax knowledge, (2) an MCP server implementation extending the protocol ecosystem to the HPC domain, (3) a multi-agent architecture with handoff mechanisms for specialized task handling, (4) integrated visualization capabilities for cluster metrics, and (5) real-time streaming response delivery using Server-Sent Events.

Experimental evaluation on a single-node Slurm cluster demonstrates high accuracy (96.9\%) in response correctness, responsive streaming interaction with time-to-first-token under 2 seconds, and effective handling of diverse query types including status queries, visualization requests, and multi-turn conversations.

The implementation provides a foundation for continued research in AI-assisted HPC operations, demonstrating the viability of LLM-based interfaces for complex system management while identifying opportunities for future enhancement including write operation support, local model deployment, and multi-cluster management.

\textbf{Keywords:} High-Performance Computing, Slurm, Large Language Models, Model Context Protocol, Multi-Agent Systems, Natural Language Interface
